# Flanker exercise (in class)

A simulated flanker dataset with a codebook, for an in-class exercise on checking an
agent's analysis. Prompt to give an agent, with no hints:

> Using the codebook's exclusion rules, test whether response times differ between
> congruent and incongruent trials. Report the estimate, a 95% confidence interval, a
> p-value, and a plot. Explain your choices.
